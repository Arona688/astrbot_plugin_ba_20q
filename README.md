# BA 猜学生

碧蓝档案（Blue Archive）主题的「二十问」猜谜：阿罗娜提问，你来回答，看她多少问能猜出你心里的角色。

## 平台与交互

| 平台 | 回答方式 |
|---|---|
| QQ 官方机器人 | 第一问点 markdown 消息里的按钮；后续点普通消息的按钮 |
| **NapCat / aiocqhttp** | 直接回复文字「是 / 不是 / 放弃」 |
| 其他适配器 | 回复文字 |

## 指令

| 指令 | 说明 |
|---|---|
| `/ba猜学生` | 开始一局 |
| `/ba猜学生 放弃` | 结束当前这局 |
| `/ba猜学生 重开` | 直接重开一局 |
| `/ba猜学生 统计` | 查看本群累计战绩 |
| `/ba猜学生 规则` | 查看玩法 |

说明：

- `ba` 不分大小写
- 指令前可以有 `@机器人` 或空格

## 一局长什么样

### 第 1 问（markdown 图文 + 按钮）

```
[146 位原版角色一览图]

👆 只从上面图里挑一位学生

第 1/12 问

❓ 她的站位是在后排吗？

（只猜原版学生，不含泳装/礼服等服装版）

[✅ 是] [❌ 不是] [🏳 放弃]
```

### 第 2 问起（普通消息 + 按钮）

```
🔮 BA 猜学生 · 第 2/12 问

❓ 她的定位是输出吗？

已答：是

[是] [不是] [放弃]
```

### 猜人

```
🤔 阿罗娜猜你想的是「日奈」，对吗？
[对！就是她] [不对]
```

## 规则与特性

- **146 位原版角色**：不含泳装 / 礼服 / 新年等服装版本
- **角色一览图**：只在第 1 问出现，方便想角色
- **二分出题**：每问尽量把候选劈成两半，平均 6 问锁定
- **确认即封盘**：某个标签答「是」后不再重复问该标签
- **矛盾拦截**：猜测必须与所有回答一致
- **12 问上限**：问满强制给答案
- **2 分钟无操作**自动结束（不计入统计）
- **图片托管**：角色图上传 QQ 素材库，用 `qqbot-media://` 引用，不依赖外部图床

## 依赖（可选）

- `astrbot_plugin_qqoffice_expand`：用于第一问的 markdown 图文消息
  - 未安装时自动降级：先单独发图片，再发普通消息问问题

## 平台兼容性
