# BA 猜学生

碧蓝档案（Blue Archive）主题的「二十问」猜谜：阿罗娜提问，你来回答，看她多少问能猜出你心里的角色。

## 平台支持

| 平台 | 回答方式 | 状态 |
|---|---|---|
| QQ 官方机器人（qq_official） | 点消息里的按钮 | ✅ 完整支持 |
| **NapCat / aiocqhttp** | **直接回复文字「是 / 不是 / 放弃」** | ✅ 支持 |
| 其他适配器 | 回复文字 | ✅ 支持 |

> NapCat 没有原生按钮，插件会自动降级：问题照常发，直接回文字即可。
> 开局会提示「没有按钮就回复文字：是 / 不是 / 放弃」。

## 指令

| 指令 | 说明 |
|---|---|
| `/ba猜学生` | 开始一局（会先发一张角色一览图） |
| `/ba猜学生 放弃` | 结束当前这局 |
| `/ba猜学生 重开` | 直接重开一局 |
| `/ba猜学生 统计` | 查看本群累计战绩 |
| `/ba猜学生 规则` | 查看玩法 |

说明：

- `ba` 不分大小写：`/BA猜学生`、`/Ba猜学生 统计` 都行
- 指令前可以有 `@机器人` 或空格
- 结束后会带两个按钮：`🔄 再来一局` / `📊 本群统计`

## 玩法

1. 发 `/ba猜学生`，先收到 146 位原版角色的头像一览图；
2. 心里想好其中一位（不用说出来），阿罗娜开始提问；
3. 回答方式：
   - QQ 官方：点按钮 `[是] [不是] [放弃]`
   - NapCat 等：回复文字 `是` / `不是` / `放弃`
4. 每局最多 12 问；她确定答案时会直接猜：

```
🤔 阿罗娜猜你想的是「日奈」，对吗？
[ 对！就是她 ]  [ 不对 ]     ← 官方按钮
回复「对」/「不对」          ← NapCat 文字
```

5. 猜中会告诉你用了几个问题，并计入本群统计。

## 规则与特性

- **146 位原版角色**：不含泳装 / 礼服 / 新年等服装版本
- **角色一览图**：开局先发，方便想角色
- **代码二分出题**：每问尽量把候选劈成两半，平均 6 问锁定
- **确认即封盘**：某个标签答「是」后不再重复问该标签
- **矛盾拦截**：猜测必须与你的所有回答一致
- **别名识别**：日文名、罗马音、常用叫法都能对上
- **12 问上限**：问满强制给答案
- **2 分钟无操作**自动结束（不计入统计）
