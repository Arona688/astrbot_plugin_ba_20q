# BA 猜学生

碧蓝档案（Blue Archive）主题的「二十问」猜谜：阿罗娜提问，你来回答，看她多少问能猜出你心里的角色。

## 指令

| 指令 | 说明 |
|---|---|
| `/ba猜学生` | 开始一局 |
| `/ba猜学生 放弃` | 结束当前这局 |
| `/ba猜学生 重开` | 直接重开一局 |
| `/ba猜学生 统计` | 查看本群累计战绩 |
| `/ba猜学生 规则` | 查看玩法 |

说明：

- `ba` 不分大小写：`/BA猜学生`、`/Ba猜学生 统计` 都行
- 指令前可以有 `@机器人` 或空格
- 结束后会带两个按钮：`🔄 再来一局` / `📊 本群统计`

## 玩法

1. 发 `/ba猜学生`，心里想好一位碧蓝档案学生（不用说出来）；
2. 阿罗娜开始提问，每题用按钮回答：

```
[ 是 ]  [ 不是 ]  [ 不确定 ]  [ 放弃 ]
```

3. 每局最多 10 次思考（可配置）；她确定答案时会直接猜：

```
🤔 阿罗娜猜你想的是「日奈」，对吗？
[ 对！就是她 ]  [ 不对 ]
```

4. 猜中会告诉你用了几个问题，并计入本群统计。

## 规则与特性

- **角色库 152 位**：SchaleDB 全部角色（服装版本合并）+ 阿罗娜、普拉娜
- **别名识别**：日文名、罗马音、常用叫法都能对上（柯伊 = 凯伊 = Kei）
- **24 个高频社团**：便利屋68、风纪委员会、C&C、游戏开发部…猜谜时可用社团提问
- **随机开局角度**：每局从学校 / 社团 / 发色 / 武器 / 性格等随机切入，不会每局都先问学校
- **已猜排除**：猜错的名字写进提示词，不会重复猜
- **每群一局**：同一群同时只允许一局
- **防连点**：1.5 秒内重复点击不会触发新调用
- **3 分钟超时**：超时自动关局，**不计入统计**
- **只统计玩完的局**：猜中计胜场，次数用完没猜中计负场；主动放弃、超时、重开都不算
- **自动重试**：模型调用失败重试一次

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `api_key` | 空 | 填了就走 DeepSeek 直连；留空用 AstrBot 当前模型 |
| `api_base` | `https://api.deepseek.com/v1` | 接口地址 |
| `model` | `deepseek-chat` | 模型名（可换 `deepseek-reasoner`） |
| `max_calls` | 10 | 每局最多调用次数（含开题） |
| `timeout` | 45 | 单次调用超时（秒） |

## 数据文件

```
data/plugin_data/astrbot_plugin_ba_20q/
├── sessions.json   进行中的对局（30 分钟清一次）
└── stats.json      各群累计战绩（永久保留）
```

删掉 `sessions.json` 只清进行中的局；删掉 `stats.json` 才会清统计。

## 常见问题

**Q：按钮没反应？**
需要 AstrBot ≥ 4.20；官方 bot 群可用原生按钮，NapCat 端不支持按钮。

**Q：同一群想两个人一起玩？**
每群一局，等一个人答完或放弃后再开。

**Q：猜得不准？**
换 `deepseek-reasoner`，或把 `max_calls` 调大。

**Q：想换题库？**
替换 `main.py` 顶部的 `NAMES`、`ALIASES`、`CLUBS` 即可。
